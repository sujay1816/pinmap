What each group does

Left border and Right border take an uploaded BMP each, which must be exactly as wide as the count you enter.

Achu pins are generated here — half up then half down, flipping on the next line. The count must be even.

Box pins are generated from how many weft files you combine.

Locking pins are woven with a weave generated here — a satin by default. Choose it from the dropdown on the Locking row: each weave states the number of pins it needs, and picking one sets that count. Your own uploaded weaves appear there too.

The weave steps once per design line, so it is applied in full to every weft file you combine. All three shuttles lay the same locking line, and each file on its own carries the complete weave.

Body takes the uploaded weft files. Empty pins stay down.

A group's name is simply its group, so there is nothing extra to type. Where the same group appears twice, as achu does, they are numbered Achu 1 and Achu 2.

Groups start in the order these pins run on the machine — achu, box, left border, locking, body, right border, achu, empty. Change any count, reorder with the arrows, or add and remove groups as a particular loom needs.

Pins you never allocate show as hollow balls and are still written into the file, kept down, at the far end.

Body wefts

Box pins and layer order

The box pattern comes from how many body wefts you load: one lifts nothing, two lift everything, and with three the first shuttle lifts every pin, the second the first half and the third the second half. A fourth lifts nothing.

Slot order is shuttle order, so the first loaded weft takes the first pattern. Empty slots are skipped.

You can change any of it. Click a pin under Box pins to turn it on or off for that weft, or use the all / first / second / none shortcuts. A row you have touched is marked "yours"; the reset button puts every weft back to the standard pattern.

Each body weft gets its own line, in slot order, so three wefts turn 500 design lines into 1500 picks. That is how the weft is laid, one shuttle at a time — so slot order is shuttle order.

On a 4 by 4 box the shuttle changes every pick, so the wefts take one line each in turn. On a 2 by 1 the shuttle must cross and come back, so each weft takes two lines before the next one starts. The loom's box motion, set when you register it, decides which.

If a design is drawn sideways, with the pins running down the file instead of across, it is turned a quarter turn anticlockwise on loading so it fits the pin count. The slot says so when that happens.

Each border has a single file. Its lines are used again on every weft pick of a design line, so the border holds still while the body wefts take their turns.

Borders are optional. Load neither and their pins simply stay blank; the body still carries only what its weft files put there.
