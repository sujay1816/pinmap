What each group does

Left border and Right border take an uploaded BMP each, which must be exactly as wide as the count you enter.

Achu pins are generated here — half up then half down, flipping on the next line. The count must be even. They only lift once a rani is loaded in the first weft slot; with no ground to bind, they stay down.

Box pins are generated from how many weft files you combine.

Locking pins are woven with a weave generated here — a satin by default. Choose it from the dropdown on the Locking row: each weave states the number of pins it needs, and picking one sets that count. Your own uploaded weaves appear there too.

The locking weave steps once per design line, so it is applied in full to every weft file you combine. All the shuttles lay the same locking line, and each file on its own carries the complete weave.

Achu is different. It alternates on every pick, so it reads the same whether you combine one weft or four.

Body takes the uploaded weft files. Empty pins stay down.

A group's name is simply its group, so there is nothing extra to type. Where the same group appears twice, as achu does, they are numbered Achu 1 and Achu 2.

To change the order, take hold of the grip at the left of a row and drag it where it belongs. With the keyboard, tab to the grip and use the up and down arrows.

Groups start in the order these pins run on the machine — achu, box, left border, locking, body, right border, achu, empty. Change any count, reorder with the arrows, or add and remove groups as a particular loom needs.

Pins you never allocate show as hollow balls and are still written into the file, kept down, at the far end.

What goes in this file

Only the border designs, and the achu that binds them. Box and locking pins belong to the body file and stay down here.

Its height is the border's own — nothing to do with how long the body is.

Make a border and the achu comes here. Make only a body and the achu goes there instead, so the two files never both carry it.

What goes in this file

The body wefts, the box pins and the locking pins. Border pins stay down here — they are in the border file.

Each body weft gets its own line, in slot order, so three wefts turn 500 design lines into 1500 picks. On a 4 by 1 box each weft takes two lines before the next starts.

The achu appears here only when the switch above is on, no border file has been loaded, and a rani is in the first weft slot. Turn the switch off and its pins stay down whatever else is true.
